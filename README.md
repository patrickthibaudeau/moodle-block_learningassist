# moodle-block_learningassist
AI Learning Assistant for students

# FOR ANYONE FOLLOWING OR FORKING THIS REPOSITORY #
I am moving this entire functionality into the block [ai_assistant](https://github.com/YorkUITInnovation/moodle-block_ai_assistant).

***The reasons:***
- It is now dependent on the RAG system called Cria (soon to be open-sourced), developed at York University
- Because of the dependency, it makes no sense to have this as a separate block.
- It will be much easier for teachers to manage.

This also means that I will no longer be working on this separate plugin for Moodle.
